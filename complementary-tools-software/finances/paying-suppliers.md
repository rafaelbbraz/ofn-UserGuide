# Pagando fornecedores com arquivos ABA (Austrália)

Usuários que operam uma loja com múltiplos fornecedores (usuários de central) frequentemente nos perguntam a forma mais rápida de encaminhar pagamentos recebidos dos clientes aos fornecedores. Por exemplo, você pode ter produtos de 20 produtores na sua loja de central. Após receber pedidos e pagamentos dos clientes, você quer uma forma rápida de calcular quanto precisa transferir a cada fornecedor e fazer o pagamento rapidamente.

Esta página descreve algumas formas de pagar seus fornecedores.

## **Calculando quanto você deve aos fornecedores**

Você pode usar [Relatórios](../../basic-features/reports/) pra obter um detalhamento do valor dos produtos vendidos de cada fornecedor. O relatório de [Totais do Ciclo por Fornecedor](../../basic-features/reports/#order-cycle-supplier-totals) dá o valor total dos produtos vendidos de cada fornecedor. Alternativamente, você pode baixar o relatório de Totais do Ciclo por Cliente e criar tabelas dinâmicas pra extrair os dados que precisa.

## **Pagando fornecedores**

Uma vez que você tem os valores em reais que precisa pagar a cada fornecedor, o próximo passo frequentemente é informar esses valores no seu sistema de internet banking pra fazer uma transferência a cada fornecedor. Isso pode ser demorado para quem tem muitos fornecedores.

No momento a Nossa Feira não tem um sistema automatizado pra calcular o que é devido aos fornecedores e automaticamente encaminhar pagamentos.

### Pagando múltiplos fornecedores rapidamente com arquivo ABA

{% hint style="info" %}
Nota: O arquivo ABA é um formato de arquivo bancário australiano, então essa opção é relevante apenas pra usuários australianos. No Brasil, o análogo seria CNAB (arquivo de remessa bancária) ou Pix em lote.
{% endhint %}

Uma alternativa pra usuários australianos é criar um arquivo ABA. Um arquivo ABA é um tipo de arquivo como uma planilha Excel que pode ser enviado pra maioria dos sistemas de internet banking australianos como forma de pagar múltiplas pessoas sem informar pagamentos individuais manualmente.

Há algumas formas de criar um arquivo ABA.

**1) Usar seu pacote de contabilidade pra gerar um arquivo ABA**

Se você usa um pacote de contabilidade como MYOB, Quickbooks ou Xero, é provável que tenha uma ferramenta de 'geração de ABA'. Essas ferramentas variam, mas geralmente permitem informar os valores que você quer pagar a cada fornecedor, junto com dados bancários (BSB, número da conta, nome etc.) e depois o arquivo ABA será gerado. Você pode então enviar esse arquivo pro banco e os pagamentos serão feitos em lote.

{% hint style="info" %}
Você pode precisar contatar seu banco pra que habilite o upload de arquivo ABA também. Também pode depender do tipo de conta bancária que você tem — confira primeiro se oferecem isso.
{% endhint %}

**2) Usar um gerador de arquivo ABA online**

Cemtexaba é um gerador de arquivo ABA online que pode transformar um arquivo Excel em ABA. Há taxas associadas — confira o site pra detalhes: [https://www.cemtexaba.com/](https://www.cemtexaba.com/)

O processo é:

1\) Baixe o template CSV Cemtexaba.

2\) Informe os detalhes nas colunas corretas. Eles pedem os dados bancários do beneficiário e o valor que você quer transferir.

3\) Faça upload do CSV no site Cemtexaba. Eles pedirão seus dados bancários (informações do 'pagador') e depois te fornecerão um arquivo ABA.

4\) Faça upload do arquivo ABA no seu internet banking pra fazer o pagamento em lote.
