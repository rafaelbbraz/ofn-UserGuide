# Produtos

* Crie 'variantes de produto' pra deixar sua vitrine menos poluída e mais fácil de navegar.

  [Leia mais ](product-variants.md)

* Estratégias pra precificar itens irregulares e indivisíveis cobrados por kg, como carne.

  [Leia mais](https://github.com/ofn-user-guide/ofn-user-guide-master/tree/d5a1113e673b0e22198ca207b1db61339799868a/pricing-irregular-indivisible-meat-items.md)

* Aplique 'propriedades de produto' aos seus produtos pra que os clientes possam ver quais itens são orgânicos, sem agrotóxicos, criados soltos etc.

  [Leia mais](inventory-tool.md)
