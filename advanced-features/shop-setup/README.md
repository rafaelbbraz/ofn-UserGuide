# Configuração da Loja

* Cobrando preços diferentes de clientes diferentes. [Leia mais](customer-specific-pricing.md)
* Tornar sua vitrine privada. [Leia mais](private-shopfront.md)
* Mantenha uma lista dos seus clientes. Isso é necessário pra usar outros recursos como tags e assinaturas. [Leia mais](customers.md)

* Você quer incorporar sua loja no seu próprio site externo? Você pode fazer isso com lojas incorporadas. [Leia mais](embedded-shopfront.md)
* Configurar impressão térmica de recibos \(disponível apenas em alguns países\). [Leia mais](thermally-printed-receipts.md)
