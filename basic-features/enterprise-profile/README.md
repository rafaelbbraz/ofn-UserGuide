# Perfil da empresa

Uma vez que você [criou sua conta de empresa](../register-and-create-your-profile.md#create-your-first-enterprise-account), faça login no [Dashboard administrativo](../dashboard.md) para continuar configurando o perfil da sua empresa.

Primeiro você será convidado a [escolher o pacote da Nossa Feira](package-types.md) (ou tipo de perfil) que melhor representa seu [modelo de negócio](../../your-quick-start-on-ofn-given-who-you-are.md).

Nesta seção detalhamos os diferentes menus que você pode preencher para refinar o perfil da sua empresa e, com isso, acessar recursos específicos que possa precisar.

{% hint style="info" %}
É importante completar todo o processo — caso contrário, sua empresa pode não aparecer no mapa ou aparecer com perfil parcialmente preenchido, o que afeta a imagem.
{% endhint %}
