# Grupos

Um grupo é um subconjunto de empresas na Nossa Feira. Uma página de grupo funciona como um subdiretório dentro da plataforma. Você pode criar um grupo, especificar os detalhes e selecionar as empresas que fazem parte dele. Esses detalhes aparecerão na sua página pública de grupo.

Empresas dentro de um grupo geralmente compartilham algum recurso ou característica em comum. Pode ser um conjunto de empresas associadas a um órgão de certificação, um grupo regional de produtores, produtores em uma rede de feira ou uma rede complexa multi-central com vários distribuidores e produtores.

Nesta seção você aprende a [criar e gerenciar uma página de grupo](group-page.md).
