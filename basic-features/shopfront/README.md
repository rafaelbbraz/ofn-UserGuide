# Vitrine

Para abrir sua loja online na Nossa Feira e começar a vender, sua empresa precisa estar cadastrada como uma Loja de Produtor ou Central Produtora/Não-Produtora. Leia mais sobre os diferentes tipos de perfil [aqui](../../your-quick-start-on-ofn-given-who-you-are.md) e [aqui](../enterprise-profile/).

Os próximos passos essenciais são configurar métodos de [Envio](shipping-methods.md) e [Pagamento](payment-methods.md) para sua empresa. Nesse estágio também sugerimos criar [Taxas da Empresa](enterprise-fees.md) (uma margem adicionada ao preço de cada produto cobrado pelo produtor fornecedor pra cobrir custos administrativos e de distribuição).

Horários de abertura e fechamento das vitrines na Nossa Feira, bem como a opção de selecionar produtos pra diferentes datas e horários de retirada, são controlados por [Ciclos de Pedidos](order-cycle/).

As vitrines na Nossa Feira são altamente flexíveis. Leia mais se você tiver interesse em:

* [Fornecer produtos e serviços diferentes para grupos de clientes diferentes](customer-management-and-conditional-displays-prices/).
* Permitir que apenas membros cadastrados possam fazer pedidos ([Loja privada](private-shopfront.md))
* Ter uma vitrine [apenas de exibição](display-only-order-cycles.md)

### Visão do cliente

Quando você abriu sua vitrine com um [Ciclo de Pedidos](order-cycle/) ativo, os clientes podem ver seus produtos listados, buscar usando a 'Caixa de Busca' no canto superior esquerdo e/ou filtrar produtos por [categorias](../products-1/) ou [propriedades](../products-1/product-properties.md):

![](../../.gitbook/assets/shopping2.gif)

Para adicionar produtos ao carrinho, o cliente clica em 'Adicionar' e depois ajusta a quantidade do item usando os botões '+' e '-'.

{% hint style="info" %}
Os clientes podem ver os itens adicionados ao carrinho no menu suspenso que aparece ao clicar no carrinho no canto superior direito.
{% endhint %}
